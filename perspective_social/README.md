# CEAR Social Perspective Wrapper — matched-control v2

This version is designed for a **scientifically matched comparison** in the
Human and Agent Belief Updating in Social Interaction pilot.

## Main comparison

Both conditions execute the same per-utterance pipeline:

```text
incoming utterance x_t
    -> raw semantic parser s_t
    -> deterministic state-relative resolver
    -> candidate state g_hat_t
    -> bounded alpha_t
    -> temporary g update
    -> identical rendered context for the base agent
```

The manipulation is only persistence:

### History-bearing perspective

```text
g_(t-1) -> ... -> g_t
                    |
                    +---- committed and used at t+1
```

### Matched reset-each-turn baseline

```text
g_0 -> ... -> temporary g'_t
                  |
                  +---- discarded
next event starts again from g_0
```

Thus semantic parsing, resolver logic, candidate-state computation, alpha law,
and prompt/render format are matched. The explicit causal ablation is whether
interaction history is carried forward in persistent perspective state.

## Why this baseline is preferable

A plain fixed-persona prompt would differ from the treatment in several ways at
once (semantic preprocessing, update computation, prompt structure, and state
persistence). The reset-each-turn control removes that confound.

The base LLM may still have ordinary conversational context in both conditions.
That is intentional: the comparison is **ordinary in-context history vs. an
additional explicit persistent perspective state**, not memory vs. amnesia.

## Experimental invariants

Use the same:

- initial participant profile / g_0
- claim
- base model and model version
- temperature / decoding parameters
- semantic parser model and prompt
- agent prompts except for wrapper state content generated by the shared path
- environment configuration
- simulation duration
- random seed where Emergentic supports it
- speaking/order rules

Use **separate state stores** for the two conditions, seeded from identical g_0.

For the cleanest causal comparison, replay the same human transcript to both
conditions. A free-running multi-agent simulation is still useful, but once the
conditions generate different responses they also generate different future
social evidence; interpret that as an endogenous system-level comparison rather
than a pure state-mechanism isolation.

## Serverless/API mapping

Treatment:

```python
result = perspective_wrapper.observe(...)
return result.conditioned_text
```

Control:

```python
result = reset_baseline_wrapper.observe(...)
return result.conditioned_text
```

The endpoint signatures can be identical. The only condition-specific behavior
should be whether `state_after` is committed.

## Logging

Every transition now records:

- `condition`
- `persistent_commit`
- `state_before`
- raw utterance / sender
- semantic observation
- resolved interpretation
- candidate state
- `alpha_t`
- `state_after`
- rendered context

## Important limitation

The update law and alpha constants are explicit heuristics, not fitted human
parameters. Do **not** tune them using the participants' mid/post debate answers
before the held-out evaluation; those answers are ground truth targets.
